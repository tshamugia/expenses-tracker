## 📱 Responsive Breakpoints

### Mobile (< 768px)
- 1 column layouts
- Full-width buttons
- Stacked navigation
- Larger touch targets

### Tablet (768px - 1024px)
- 2 column grids
- Optimized spacing
- Adaptive typography
- Touch-friendly buttons

### Desktop (> 1024px)
- 3-4 column grids
- Full spacing
- Large typography
- Multi-line content

## 🎬 Animation Types

### Entrance Animations
```
fadeInUp
├─ Initial: opacity 0, y +20px
└─ Animate: opacity 1, y 0

slideInLeft/Right
├─ Initial: opacity 0, x ±50px
└─ Animate: opacity 1, x 0

scaleIn
├─ Initial: opacity 0, scale 0.9
└─ Animate: opacity 1, scale 1
```

### Interactive Animations
```
hoverScale
└─ Hover: scale 1.05

hoverScaleUp
└─ Hover: scale 1.1, y -5

buttonHover
└─ Hover: scale 1.02, shadow increase

cardHover
└─ Hover: y -10, shadow increase
```

### Continuous Animations
```
Floating Elements
├─ Y position: [0, 30, 0]
└─ Duration: 8s infinite

Background Blobs
├─ Movement patterns
└─ Opacity effects
```

## 🎯 Content Density

### Information Hierarchy
```
Level 1: Headlines (h2, text-5xl)
Level 2: Subheadings (h3, text-lg)
Level 3: Body Text (p, text-base)
Level 4: Meta Info (p, text-sm)
```

### Visual Weight
```
Heavy:     Large headings, blue backgrounds
Medium:    Feature cards, pricing cards
Light:     Body text, secondary text, borders
Accent:    CTAs, badges, checkmarks
```
